# Subordinate clauses

A subordinate (dependent) clause opens with a subordinating conjunction (because, although, since, if, while) or a relative pronoun (that, who, which) and cannot stand on its own as a sentence.

## Punctuation rules

**Subordinate clause before the main clause** takes a comma.
- *Although the server had been patched twice, the exploit still worked.*

**Subordinate clause after the main clause** takes no comma.
- *The migration failed silently because nobody checked the return code.*

## Using subordination for emphasis

Put the idea you want to stress in the independent clause, which usually falls at the end of the sentence.
- Weaker: *When the model started hallucinating citations, the reviewer flagged the paper.* (stresses the reviewer's action)
- Stronger: *The reviewer flagged the paper when the model started hallucinating citations.* (stresses the hallucination)
