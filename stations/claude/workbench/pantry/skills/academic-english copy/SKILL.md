# Academic English

## Overview

Reference rules for academic writing style and grammar: when to use which construction, and
a concrete before/after example for each. One rule per file under `rules/`, so a fix pulls in
just the one relevant file instead of the whole set.

Style rules informed by Brandeis University's Writing Program handouts
(https://www.brandeis.edu/writing-program/) and, for `dashes-rules` and `sentence-patterns`,
UNC-Chapel Hill's Writing Center (https://writingcenter.unc.edu/), rewritten from scratch as
original reference material — same teaching points, none of the original wording or example
sentences.

## When to use

Reach for a specific rule file below whenever prose being written or edited has one of these
issues. Read only the file(s) that match — don't load the whole set for a single fix.
